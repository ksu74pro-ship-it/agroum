# АгроУМ — лаборатория семечка

Готовый образовательный веб-симулятор. Работает **без Python, React, сервера, сборки и зависимостей**: HTML + CSS + JavaScript + SVG.

## Как опубликовать на GitHub Pages (5 минут)

1. Создайте **публичный** репозиторий на GitHub, например `agroum-seed-lab`.
2. Откройте репозиторий → **Add file → Upload files**.
3. Загрузите **содержимое папки** `agroum-seed-lab`, а не ZIP: `index.html`, `styles.css`, `app.js` и папку `assets` с логотипом и иконкой. Нажмите **Commit changes**.
4. Откройте **Settings → Pages → Build and deployment → Source: Deploy from a branch**.
5. Выберите **Branch: main**, **Folder: /(root)** → **Save**.
6. Дождитесь публикации. Ссылка будет вида `https://ВАШ-ЛОГИН.github.io/agroum-seed-lab/` (если репозиторий так назван).

Если GitHub не позволяет загрузить папку через браузер, используйте обычное перетаскивание всех файлов, включая `assets` с её содержимым, либо загрузите распакованную папку с помощью GitHub Desktop / Git. **Не загружайте один ZIP**, иначе сайт не запустится.

## Что умеет сайт

- **4 культуры:** базилик, редис, горох и подсолнечник. Отличаются скоростью развития, запросами к среде и рисунком растения.
- **30 дней**, пошаговое перемещение и автоматическое воспроизведение.
- **Жизнь растения с историей:** засуха, перелив, жара, темнота, дефицит и избыток питания. Нарушения способны накопиться и привести к повреждению корней или гибели.
- **5 регулируемых параметров:** полив, температура, освещение, питание и дренаж.
- **Увеличенное строение семени и корней**, прозрачный разрез субстрата, экспорт иллюстрации растения в SVG.
- **Контрольный вариант и графики** высоты, здоровья и влажности.
- **Дневник**, экспорт в CSV, сохранение и загрузка эксперимента в JSON.
- Автосохранение в локальном хранилище браузера.
- Мобильная адаптация, сайт работает без обращения к сторонним CDN.

## Важно о биологии

Это **качественная учебная симуляция**, а не точная агрономическая модель. Визуализация строения упрощена, рисунки и численные параметры не в масштабе. Показатели «здоровье», «кислород», «влажность» — условные индексы. Объёмы полива условны для модельного контейнера. Модель нельзя использовать как агротехнический норматив.

Составьте с детьми гипотезу, получите прогноз в симуляторе и проверьте его на настоящих растениях. Значимое отличие между предсказанием и результатом — исследовательская задача, а не «ошибка ребёнка».

## Локальный запуск

Можно открыть `index.html` прямо в браузере. Если браузер ограничивает доступ к локальным файлам, используйте простой локальный сервер: `python -m http.server 8000` и откройте `http://localhost:8000` (Python нужен только как удобный способ локальной проверки, самому сайту он не нужен).
